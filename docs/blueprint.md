# **App Name**: FalaaData

## Core Features:

- Smart Wallet Dashboard: An intuitive dashboard displaying real-time balance, unique deposit references, and chronological transaction logs.
- Automated MoMo Funding: Secure webhook listener that validates iPhone-shortcut triggers to automatically credit user balances upon payment detection.
- Single-Click Bundle Ordering: Simplified UI featuring Plan A (3.4GB) and Plan B (5.1GB) with automated validation against user balance.
- Silent API Bridge: Internal integration for the Rahitalu API with automated login and silent token refresh logic to ensure zero-downtime purchases.
- Live Order Tracking: Visual feedback system transitioning statuses from pending through processing to delivered in real-time.
- AI Usage Forecasting Tool: Generative AI tool that analyzes previous bundle purchase history to provide data depletion estimates and recommended top-up dates.
- Global Admin Nexus: Central management console for tracking system stats, user wallet balances, and performing manual credit adjustments.

## Style Guidelines:

- A sophisticated dark theme inspired by high-frequency financial platforms. Primary color is a vibrant Digital Blue (#4766F5) providing a machined and precise aesthetic.
- Background is a deep midnight hue (#14171F), creating a professional contrast with the primary Indigo. Accent color is a sharp Cerulean (#26A3D9) used for focus states and tool indicators.
- We recommend using 'Inter' for its grotesque-style, objective feel. Its machined appearance and excellent legibility across small numerical data and large dashboard stats suit the utilitarian nature of the app.
- Geometric monolinear icons from a refined set to indicate transactions, wallets, and status updates, emphasizing precision and speed.
- Grid-focused modular cards within a contained dashboard view, optimizing the scan-ability of order history and account status.
- High-speed, subtle transitions for order status changes and stateful button indicators to provide instant haptic-like visual feedback.
